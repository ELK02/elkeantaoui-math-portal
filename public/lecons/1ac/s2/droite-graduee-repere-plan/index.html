I

La droite graduée

Le point de départ pour repérer un point sur un axe

Définition

Une droite graduée (axe gradué) est une droite sur laquelle on choisit :

  • —un sens selon lequel on parcourt la droite ;
  • —un point origine O : l'origine de la graduation ;
  • —une unité de longueur : OI = 1 cm.

Exemple

  • • Le point O : l'origine de la droite ;
  • • la distance OI : l'unité ;
  • • le point I appelé « point d'unité ».
II

Abscisse d'un point

Chaque point d'une droite graduée porte un nombre

Définition

Chaque point d'une droite graduée est repéré par un nombre appelé abscisse du point. L'abscisse d'un point A se note xA.

Exemple

L'abscisse de O est 0, on note O(0) ou xO = 0

L'abscisse de I est +1, on note I(+1) ou xI = 1

L'abscisse de A est +2, on note A(+2) ou xA = 2

L'abscisse de B est −3, on note B(−3) ou xB = −3

L'abscisse de C est +4, on note C(+4) ou xC = 4

L'abscisse de D est −2,5, on note D(−2,5) ou xD = −2,5

L'abscisse de E est +4,5, on note E(+4,5) ou xE = 4,5

III

Distance sur une droite graduée

Toujours la plus grande abscisse moins la plus petite

Définition

La distance entre deux points A et B sur une droite graduée est la longueur du segment [AB]. Pour la calculer, on effectue la différence entre l'abscisse la plus grande et l'abscisse la plus petite :

AB = plus grande abscisse − plus petite abscisse

Exemple — sur une droite graduée : A(+2) ; B(−3) et C(+4)

Puisque xB < xA, alors :

AB = xA − xB = 2 − (−3) = 2 + 3 = 5

Puisque xC > xA, alors :

AC = xC − xA = 4 − 2 = 2

💡

Remarque : une distance est toujours positive.

IV

Repère dans le plan

Deux droites graduées pour repérer un point du plan

Définition

Un repère du plan est un repère orthogonal constitué de deux droites graduées perpendiculaires ayant la même origine.

V

Coordonnées d'un point

Repérer un point du plan par un couple de nombres

Définition

Dans le plan muni d'un repère orthogonal, on peut repérer un point par deux nombres appelés les coordonnées du point :

  • ▪le premier nombre s'appelle l'abscisse du point et se lit sur l'axe des abscisses ;
  • ▪le second nombre s'appelle l'ordonnée du point et se lit sur l'axe des ordonnées.

Remarque : le couple relatif (abscisse ; ordonnée), toujours donné dans cet ordre, définit les coordonnées du point.

L'abscisse de M est notée xM, l'ordonnée de M est notée yM — on écrit M(xM ; yM).

Exemple

L'origine a pour abscisse et ordonnée zéro : O(0 ; 0)

Le point A a pour coordonnées : A(1 ; 2)

Le point B a pour coordonnées : B(−1 ; −1)

Le point C a pour coordonnées : C(−2 ; −3)

Le point D a pour coordonnées : D(−2 ; 1)

Le point E a pour coordonnées : E(2 ; −1)

Le point F a pour coordonnées : F(−4 ; −1)

Le point G a pour coordonnées : G(−1 ; 3)

Le point I a pour coordonnées : I(3,5 ; 4)

1 Exercice n°1

Sur une droite graduée au centimètre, d'origine O, place les points A, B, C, D et E d'abscisse :

A(−2,5) ; xB = +3,5 ; xC = −1 ; D(2) ; E(+2,5).

Donner les distances AB, CD, AC, BD, AE, BE, EC et DE.

Figure

AB = xB − xA = 3,5 − (−2,5) = 6
CD = xD − xC = 2 − (−1) = 3
AC = xC − xA = −1 − (−2,5) = 1,5
BD = xB − xD = 3,5 − 2 = 1,5
AE = xE − xA = 2,5 − (−2,5) = 5
BE = xB − xE = 3,5 − 2,5 = 1
EC = xE − xC = 2,5 − (−1) = 3,5
DE = xE − xD = 2,5 − 2 = 0,5

2 Exercice n°2

Sur papier quadrillé, tracer un repère orthogonal d'origine O avec pour unité un carreau sur chaque axe.

  1. Placer les points : M(6 ; 5), N(6 ; −3), P(−6 ; −3), Q(−6 ; 5).
  2. Que peut-on dire du quadrilatère MNPQ ?
  3. Écrire les coordonnées du point d'intersection A des diagonales de MNPQ.

Figure

2) [MN] et [PQ] sont verticaux (M, N ont la même abscisse 6 ; P, Q ont la même abscisse −6) et [NP], [QM] sont horizontaux (N, P ont la même ordonnée −3 ; Q, M ont la même ordonnée 5). MN = PQ = 8 et NP = QM = 12 : les côtés opposés sont donc parallèles et de même longueur, et les angles sont droits. MNPQ est un rectangle.
3) Dans un rectangle, les diagonales [MP] et [NQ] se coupent en leur milieu commun. A = milieu de [MP] : xA = (6 + (−6))/2 = 0 et yA = (5 + (−3))/2 = 1. D'où A(0 ; 1).

3 Exercice n°3

Dans un repère, placer les points A(−5 ; −3) et B(3 ; −1). Tracer le segment [AB], placer le milieu M de ce segment et lire ses coordonnées.

Figure

Les coordonnées du milieu M d'un segment [AB] sont la moyenne des coordonnées de A et de B :
xM = (xA + xB)/2 = (−5 + 3)/2 = −1    yM = (yA + yB)/2 = (−3 + (−1))/2 = −2
D'où M(−1 ; −2).

7 Exercice n°7 — devinette

Je suis un nombre entier relatif.

Ma distance à zéro est comprise entre 10,7 et 19,3.

Mon opposé est compris entre 5,75 et 11,3.

Qui suis-je ?

Notons n ce nombre. Sa distance à zéro est |n|, donc |n| ∈ ]10,7 ; 19,3[, soit |n| ∈ {11, 12, …, 19}.
Son opposé est −n, donc −n ∈ ]5,75 ; 11,3[, soit −n ∈ {6, 7, …, 11}, c'est-à-dire n ∈ {−6, −7, …, −11}. n est donc négatif.
Comme n est négatif, |n| = −n. La première condition donne alors −n ∈ {11, …, 19}. En combinant avec −n ∈ {6, …, 11}, la seule valeur commune est −n = 11.

Visualisation des deux conditions

Je suis −11
