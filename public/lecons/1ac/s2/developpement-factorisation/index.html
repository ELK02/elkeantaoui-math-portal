I

Développement

Transformer un produit en une somme ou une différence

1. Définition

Le développement, c'est l'écriture d'un produit en une somme ou en une différence.

2. Propriétés

a) Produit d'un nombre par une somme

Soient a, b et k des nombres relatifs.

k×(a + b) = k×a + k×b

(a + b)×k = k×a + k×b

Exemples — développons puis calculons :

2 × (1 + 5) = 2×1 + 2×5

= 2 + 10

= 12

(-10 + 3) × (-1,5) = -1,5×(-10) + (-1,5)×3

= 15 + (-4,5) = 15 - 4,5

= 10,5

b) Produit d'un nombre par une différence

Soient a, b et k des nombres relatifs.

k×(a - b) = k×a - k×b

(a - b)×k = k×a - k×b

Exemples — développons puis calculons :

1,2 × (10 - 2) = 1,2×10 - 1,2×2

= 12 - 2,4

= 9,6

(-8 - 5) × (-4) = -4×(-8) - (-4)×5

= 32 - (-20) = 32 + 20

= 52

c) Produit de deux sommes / deux différences

Soient a, b, c et d des nombres relatifs.

(a + b)×(c + d) = ac + ad + bc + bd

(a - b)×(c - d) = ac - ad - bc + bd

Exemples — développons puis calculons :

(2,5+10)(5+1) = 2,5×5+2,5×1+10×5+10×1

= 12,5+2,5+50+10

= 75

(4-12)(15-6) = 4×15-4×6-12×15+12×6

= 60-24-180+72 = 60+72-24-180

= -72

3. Développement et calcul littéral

A = 2x(x + 1)

= 2x2 + 2x

B = -3x(-x+1) + x(2x+4)

= 3x2-3x+2x2+4x

= 5x2 + x

C = (2x-1)(-3x-2)

= 6x2-4x+3x+2

= 6x2 - x + 2

D = 2x(-x2+3x-1) + 2x2(5x-2)

= -2x3+6x2-2x+10x3-4x2

= 8x3 + 2x2 - 2x

✨ Cas particuliers : les identités remarquables

Trois développements à connaître par cœur, illustrés à partir des exemples du cours.

(a+b)² = a²+2ab+b²

(2x+1)² = (2x+1)(2x+1)

= 4x2+2x+2x+1

= 4x2+4x+1

(a-b)² = a²-2ab+b²

(3x-2)² = (3x-2)(3x-2)

= 9x2-6x-6x+4

= 9x2-12x+4

(a+b)(a-b) = a²-b²

(4x-5)(4x+5)

= 16x2+20x-20x-25

= 16x2-25

II

Factorisation

Transformer une somme ou une différence en un produit

1. Définition

La factorisation, c'est l'écriture d'une somme ou d'une différence en un produit.

2. Propriétés

Soient a, b et k des nombres relatifs.

k×a + k×b = k×(a + b)

k×a - k×b = k×(a - b)

k est appelé facteur commun

💡

Remarque : pour factoriser, on cherche d'abord le facteur commun.

Exemples — factorisons puis calculons :

a = 2×7 + 2×11 = 2(7+11)

= 2×18

= 36

b = -5×(-10) - (-5)×22 = -5(-10-22)

= -5×(-32)

= 160

4. Factorisation et calcul littéral

A = 3a3b4 + 7a2b7c

= a2b4(3a + 7b3c)

B = 12a5b4c2+6a2b2c2-18a4b3c4

= 6a2b2c2(2a3b2+1-3a2bc2)

C = 6x4 + 4x2 - 2x

= 2x(3x3 + 2x - 1)

D = 2x(x+1) + 3(x+1)

= (x+1)(2x+3)

E = (2x+3)² + 3x(2x+3) - (2x+3)

= (2x+3)(2x+3) + 3x(2x+3) - (2x+3)

= (2x+3)(2x+3+3x-1)

= (2x+3)(5x+2)

7 Exercice n°7 — Deux programmes de calcul

  1. Choisir un nombre
  2. Multiplier par 3
  3. Soustraire 2 au résultat
  4. Multiplier le tout par le nombre choisi au départ
  1. Choisir un nombre
  2. Calculer son carré
  3. Multiplier le résultat par 3
  4. Soustraire le double du nombre choisi au début
  1. Appliquer les programmes de calcul au nombre 5. Que constate-t-on ?
  2. Prouver que les deux programmes de calcul donnent le même résultat pour n'importe quel nombre choisi au départ.

1) Avec le nombre 5 :

Programme 1 : 5×3 = 15 ; 15-2 = 13 ; 13×5 = 65

Programme 2 : 52 = 25 ; 25×3 = 75 ; 75-2×5 = 65

On constate que les deux programmes donnent le même résultat : 65.

2) Preuve : soit n le nombre choisi au départ.

Programme 1 : (3n - 2) × n = 3n2 - 2n

Programme 2 : n2×3 - 2n = 3n2 - 2n

Les deux expressions sont identiques : 3n2-2n = 3n2-2n.

Les deux programmes donnent donc toujours le même résultat, quel que soit le nombre n choisi.

8 Exercice n°8 — Deux programmes de calcul

  1. Choisir un nombre
  2. Calculer la somme de son carré, de son double et de 1
  3. Annoncer le résultat
  1. Choisir un nombre
  2. Lui ajouter 1
  3. Puis calculer le carré du résultat obtenu
  4. Annoncer le résultat
  1. Appliquer les programmes de calcul au nombre 3. Que constate-t-on ?
  2. Prouver que cela est vrai quelle que soit la valeur choisie.

1) Avec le nombre 3 :

Programme 1 : 32 + 2×3 + 1 = 9+6+1 = 16

Programme 2 : (3+1)2 = 42 = 16

On constate que les deux programmes donnent le même résultat : 16.

2) Preuve : soit n le nombre choisi.

Programme 1 : n2 + 2n + 1

Programme 2 : (n+1)2 = n2+2n+1

n2+2n+1 = (n+1)2 (identité remarquable)

Les deux programmes donnent donc toujours le même résultat, quel que soit n.

11 Exercice n°11 — Démontrer une égalité

A = (3x+4)(5x-2) - (20x-12)

B = 4 - 3x(2-5x)

Démontrer que A = B.

A = 15x2-6x+20x-8-20x+12

A = 15x2-6x+4

B = 4-6x+15x2

B = 15x2-6x+4

A et B sont deux écritures de la même expression 15x²-6x+4, donc A = B. ✓

13 Exercice n°13 — Deux programmes de calcul

  1. Choisir un nombre

On constate que les deux programmes donnent le même résultat : 100.

2) Preuve : soit n le nombre choisi.

Programme 1 : n2 + 4n + 4

n2+4n+4 = (n+2)2 (identité remarquable)

La remarque est donc vraie quelle que soit la valeur de n choisie.
