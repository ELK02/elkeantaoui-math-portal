01 — La définition

C'est quoi, une puissance ?

Une façon rapide d'écrire « je multiplie a par lui-même, n fois ».

an = a × a × a × ... × a

n facteurs

la base

an — a est le nombre qu'on multiplie

l'exposant

an — n dit combien de fois

a⁰ = 1
a¹ = a
0⁰ n'existe pas

exemples

35 = 3 × 3 × 3 × 3 × 3

1,23 = 1,2 × 1,2 × 1,2

(−7)4 = (−7) × (−7) × (−7) × (−7)

1240 = 1

02 — Le piège classique

Positif ou négatif ?

Pour une base négative, un seul réflexe à avoir : compter pair ou impair.

exposant pair

(−a)n est positif

(−21,5)124 > 0 · 124 est pair

exposant impair

(−a)n est négatif

(−225)217 < 0 · 217 est impair

⚠ Attention à ne pas confondre

(−a)n ≠ −an en général

(−3,5)² = +3,5 × 3,5 = 12,25

(−3)⁵ = −3 × 3 × 3 × 3 × 3 = −729

Les puissances de 10

L'exposant compte directement les zéros. Rien à calculer.

10n = 1 000...0

n zéros

103 = 1 000

04 — Les 5 règles à connaître

Propriétés des puissances

Toujours la même idée : on additionne ou on multiplie les exposants selon le cas.

même base · produit

am × an = am+n

2,512 × 2,57 = 2,519

même base · quotient

aman = am−n

1125 ÷ 1111 = 1114

même exposant · produit

am × bm = (ab)m

47 × 157 = 607

même exposant · quotient

ambm = (ab)m

2511 ÷ 511 = 511

puissance d'une puissance

(am)n = am×n

(2313)10 = 23130
